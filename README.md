# ArtNotes — atlante interattivo di storia dell'arte

Progetto in fase di prototipo. Opere, dettagli visivi e conoscenza storico-artistica documentata, con una base documentale sempre visibile.

**Prototipo online:** apri `prototipo/web/` dal sito GitHub Pages del repository.

## Documenti

- [ISTRUZIONI.md](ISTRUZIONI.md) — specifica di prodotto
- [FASE1_rapporto.md](FASE1_rapporto.md) e [FASE1_matrice_fonti.md](FASE1_matrice_fonti.md) — ricognizione delle fonti
- [FASE2_rapporto.md](FASE2_rapporto.md) — prototipo dell'esperienza visiva
- [prototipo/README.md](prototipo/README.md) — avvio locale e struttura

## Avvertenza

I testi e le regioni del prototipo sono **bozze generate da AI e non revisionate**, mostrate in anteprima redazionale. Ogni frase porta il proprio registro (documentato, osservazione, ipotesi, lacuna) e la propria fonte.
